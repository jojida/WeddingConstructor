# Диалог: доработка шаблона «Скетч»

Лог работы над свадебным приглашением «Скетч» (Артём и Екатерина).
Шаблон: `frontend/public/invite/sketch/` (статический HTML) + превью-карточка `frontend/src/components/SketchTemplate.tsx`.

---

## 1. Чекбоксы, дресс-код, рамки — первые правки

**Запрос:** в превью в «Избранных стилях» не тот шрифт и расположение; в дресс-коде рамки обрезаны; в «Что предпочитаете из напитков» в квадратиках должны ставиться галочки; рамка «До новых встреч» съехала.

**Сделано:**
- Чекбоксы: `content: '✓'` при `:checked`, для радио — круглая точка.
- Подключён шрифт **HitchHike** в `globals.css` (`@font-face`), чтобы превью-компонент Next.js его видел.

---

## 2. Дресс-код: «рамки дублируются»

**Проблема:** PNG-файлы платьев (`dress1.png`/`dress2.png`) имели **впечатанную** красную рамку. Сверху накладывалась ещё одна `frame-red.svg` → двойная рамка. Плюс кропы были кривые — фото вылезало за рамку.

**Путь решения:**
1. Вырезал оба платья **одним блоком** `dress_block.png` прямо из оригинала `2.png` (точная раскладка 1:1, без артефактов нарезки) — временное решение.
2. Итог: **разделил на слои** (см. п. 5).

---

## 3. «До новых встреч»: фото и рамка

**Проблема:** фото пары не помещалось / съезжало; правый край синей рамки был обрезан (кроп заканчивался на x=1018, а реальный край рамки на x=1268).

**Сделано:**
- Перевырезал полный композит, затем перешёл на слои.
- Сердечки `hearts-navy.png` вынесены **отдельным элементом** поверх рамки (`z-index:3`), вычищен вшитый кусочек сердца из фото пары.

## 4. Откуда брать код с Canva-сайта

**Вопрос:** можно ли взять код с `wedinviteqq.my.canva.site`?

**Ответ:** напрямую нельзя — Canva-сайт это JS-приложение, отдаёт пустую оболочку. Но в `Downloads/Ждем вас на нашей свадьбе!/` лежат экспорты: 2 PNG полных страниц + 24 SVG-слоя. По ним вырезаются высокоточные фрагменты (как сделано с платьями и фото пары).

**Находки в SVG-слоях:**
- SVG(19) = красная рамка (идентична `frame-red.svg`), SVG(22) = синяя рамка.
- Встроенные картинки SVG(3/4/21/23) — семья / девочка с камерой / текстура / маска (не платья).

## 5. Главная архитектурная правка: слои для конструктора

**Запрос:** рамка и фото не должны быть одним элементом — в конструкторе нужно менять фото, рамка остаётся.

**Решение — два слоя на каждое фото:**
```html
<div class="framed">
  <img class="photo" src="ЛЮБОЕ_ФОТО">    <!-- меняется -->
  <img class="frame" src="frame-blue.svg"> <!-- рамка сверху, прозрачная внутри -->
</div>
```
- Фото: `position:absolute` + `object-fit:cover` → заполняет окно и **обрезается рамкой**.
- Рамка: `z-index:2`, `pointer-events:none`.
- Применено ко всем трём фото: пара (`frame-blue.svg`), платье 1 и платье 2 (`frame-red.svg`).
- Удалены запечённые `dress_block.png`, `couple_framed.png`.

## 6. Чистые фото без рамок

**Проблема:** кропы платьев из оригинала тащили красные завитки → снова дублирование.

**Решение:** взяты чистые фото без рамок (`couple.png`, чистые платья), завитки из исходников больше не используются.

## 7. Превью-карточка = обложка шаблона

**Проблема:** превью в «Избранных стилях» не совпадало с обложкой реального шаблона.

**Решение:** переписал превью-ветку `SketchTemplate.tsx` **точной копией обложки** теми же px-значениями (карточка рендерится на ~488px ≈ ширина обложки ~460px):
- «МЫ женимся!» — крупный чёрный HitchHike, слева, со сдвигом второй строки;
- конфетти + **розовые сердечки** справа;
- имена справа с розовым подчёркиванием;
- два полароида Жених/Невеста с наклоном.
- Подключён шрифт **Caveat** в `globals.css` (для бейджа «Наконец-то!»).
- Имена берутся из данных (`groomName`/`brideName`).
- Фикс: в сигнатуру добавлен проп `data` (была ошибка `data is not defined`).

## 8. Заполнение рамок: фото целиком в окне

**Метод:** прозрачное окно каждой SVG-рамки измеряется через `canvas` (альфа-канал) — берутся **крайние** точки волнистой внутренней границы, фото подгоняется чуть шире окна, чтобы края ушли под рамку без зазоров.

**Окна рамок (% от габарита):**
| Рамка | left | right | top | bottom |
|-------|------|-------|-----|--------|
| `frame-blue.svg` (пара) | 7.8 | 90.0 | 6.6 | 94.2 |
| `frame-red.svg` (платья) | 4.3 | 95.3 | 1.7 | 98.1 |

**Итоговый CSS:**
```css
.framed .photo {        /* фото пары */
  top: 6%; left: 6.5%; width: 85%; height: 88.5%;
  object-fit: cover; object-position: center 35%;
}
.dress-pic .photo {     /* платья */
  top: 1.5%; left: 4%; width: 92%; height: 97%;
  object-fit: cover; object-position: center;
}
```

**Проверка (canvas-композит, поиск белых пикселей-зазоров в зоне окна):**
- фото пары — 0.01% (блики неба, не дыры);
- платье 1 — 0.04%; платье 2 — 0.00%.

## Техническая заметка

Chrome-скриншоты **стабильно подвисают** при рендере секций с крупными фото + SVG-рамкой (outro, дресс-код).
Обход: проверка результата через **canvas-композит и пиксельный анализ** прямо в браузере (`javascript_tool`) вместо скриншотов.
