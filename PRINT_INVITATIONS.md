# Печатные приглашения WeddingCraft

## Продукт

- `/print`: коллекция одиннадцати дизайнов, фильтры стилей, инструкции и FAQ. Новые: «Свадебный вестник», «Шёпот лепестков», «Наша история» и «Рейс в счастье».
- `/print/editor?template=olive`: редактирование до оплаты, водяной знак на превью, локальный черновик.
- `/print/editor?order=<id>`: сохранённый заказ, оплата, повторное редактирование и скачивание.
- `/print/orders`: отдельный список заказов в аккаунте, ссылка из основного кабинета.
- 290 ₽ за один дизайн. Печать, бумага и доставка не входят. Покупка сайта не требуется.
- PDF A6 105 × 148 мм; вариант с вылетами 3 мм — 111 × 154 мм, с TrimBox и BleedBox.
- Векторные элементы и встроенный Cormorant Garamond (OFL). PDF в RGB: цветопробу и нужный профиль согласовывают с типографией.

## Конкуренты, изученные 28 сентября 2026

- https://zovemvas.space/ — каталог, бесплатная персонализация, оплата при скачивании, файлы в аккаунте.
- https://weddingpost.ru/cabinet/constructor/paper/ — отдельный раздел бумажных приглашений, данные свадьбы, покупка PDF отдельно от заказа печати.
- https://wedsday.ru/tools/print-kit — редактирование и скачивание печатных материалов, объяснение форматов и печати.

Использован знакомый покупателю сценарий «дизайн → данные → предпросмотр → оплата → файл». Иллюстрации и макеты написаны для WeddingCraft, чужие файлы не используются.

## Реализация

`backend/src/lib/printDesign.ts` — единый SVG-рендерер для превью и PDF, валидация текста, цена на сервере.
`backend/src/routes/print.ts` — приватные заказы, ЮKassa, PDF. Подтверждение платежа проверяет продукт, заказ, идентификатор платежа, ключ идемпотентности и сумму 290.00 RUB. Вебхук использует существующий `/api/payment/webhook`; статус заказа дополнительно перечитывает платёж из ЮKassa.

`PrintOrder` отделён от `Invitation`: оплата печатного макета не открывает публикацию сайта. Дизайн оплаченного заказа неизменяем, текст можно менять. У всех приватных методов проверяется владелец. Предпросмотр всегда содержит водяной знак; чистый PDF отдаётся только владельцу оплаченного заказа.

После изменения макетов: `npm --prefix backend run build`, затем `node scripts/generate-print-previews.cjs`. Двенадцать SVG-превью сохраняются в `frontend/public/print/`.

Иллюстрации новых макетов находятся в `backend/assets/print-art/`, источники и запросы генерации — в README этой папки. Содержимое изображений встроено в SVG/PDF; папку assets нужно включать в развёртывание backend. В газете, журнале и цветочных шаблонах можно заменить фото, выбрать положение в рамке и вернуть исходное изображение. Фото сохраняется в заказе и PDF. Голубая акварель — горизонтальный формат 148 × 105 мм. `node scripts/check-print-collection.cjs` проверяет композиции; с флагом `--ui` и frontend на порту 3010 дополнительно проверяет фильтры, мобильную ширину и редактор с локальной подменой preview API.

## Обновление сервера

Нужны обновлённые зависимости backend (`npm ci`), генерация клиента Prisma (`npx prisma generate`), сборка backend и frontend, перезапуск обоих процессов. Новая таблица создаётся идемпотентно существующим `ensureSchema` при старте backend. Также добавлена SQL-миграция для новых установок. Не запускать `prisma migrate reset` или разрушительное выравнивание рабочей базы.

Используются существующие ключи ЮKassa, FRONTEND_URL и настройка чеков YOOKASSA_RECEIPT. Без настроенной кассы API возвращает 503 и сохраняет заказ без права скачивания. Подмена оплаты в production отсутствует.

Проверка: `npm --prefix backend test`; `frontend/node_modules/.bin/tsc --noEmit --incremental false` из frontend; ESLint для новых компонентов. API-тесты используют отдельную временную базу и имитацию ответов ЮKassa, не проводят реальные платежи.
