# Сессия: анимация открытия свадебного конверта

Дата: 2026-06-11
Проект: WeddingConstructor (Next.js фронтенд + статические HTML-шаблоны приглашений)

---

## Что просили

Создать **премиальную анимацию открытия свадебного конверта** и применить её к шаблону.

Требования к механике:
- конверт в центре экрана, верхний клапан — отдельный элемент;
- по клику на кнопку **Open Invitation** клапан открывается вокруг верхней оси
  (`transform-origin: top center`, `rotateX(0deg → -180deg)`, длительность 1.2s,
  плавность `cubic-bezier(0.22, 1, 0.36, 1)`);
- после открытия из конверта плавно выезжает карточка приглашения с лёгким overshoot;
- технологии: **GSAP**, CSS 3D transforms, perspective, реалистичные тени,
  имитация motion blur, послойная глубина;
- отдельные слои: конверт / клапан / карточка / тени / фоновое затемнение;
- никаких простых fade-in; ощущение настоящей бумаги.

Исходные ассеты: три SVG-файла из `C:\Users\Asus\Downloads\коверт\` — `2.svg`, `3.svg`, `4.svg`.

## Что выяснили про SVG-файлы

Файлы оказались очень тяжёлыми (0.8–2.9 МБ) — это растровые PNG, запакованные
в SVG как base64 c luminance-масками. Прочитать как текст нельзя.

Проанализировал их пиксельно (canvas + сетка цветов). Результат:

| Файл  | Роль на картинке            | Средний цвет        | Красных пикселей |
|-------|-----------------------------|---------------------|------------------|
| 2.svg | светлый треугольный клапан  | `rgb(232,231,228)`  | 0%               |
| 3.svg | открытый конверт (кремовый) | `rgb(225,223,205)`  | 0%               |
| 4.svg | карточка-арка (белая)       | `rgb(229,229,229)`  | 0%               |

**Вывод:** файлы кремово-белые, а не красные.

## Технические заметки

- **Скриншоты в превью зависали** на тяжёлых SVG — проверка велась через
  `preview_eval` (чтение состояния DOM, средние цвета на canvas).
- **GSAP не тикал в iframe**: `document.visibilityState === 'hidden'` →
  браузер тротлит `requestAnimationFrame`. Решалось шимом RAF на `setTimeout(16ms)`.
- `gsap.ticker.useRAF()` в GSAP 3 не существует — эта строка ломала весь IIFE,
  её убрали.
