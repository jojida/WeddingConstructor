# Шаблон «Каллы» (calla) — лог беседы

Сессия по созданию свадебного приглашения из папки `calalilies/` и его интеграции
в конструктор как редактируемого шаблона.

---

## Часть 1 — Вёрстка из SVG-макета

### Запрос пользователя
> Есть папка `calalilies`. Там структура сайта — `1.svg`, `2.svg` … (объединить в одну
> страницу) и иконки «Текст абзаца». Создай адаптивную HTML/CSS-вёрстку.
>
> ВАЖНО:
> - Не создавай новый дизайн, не интерпретируй/не улучшай макет, не меняй композицию.
> - Не подбирай похожие шрифты, если оригинальные доступны.
> - Используй предоставленные изображения, иконки и декоративные элементы.
> - Сохрани размеры, отступы, цвета и расположение максимально близко к макету.
> - SVG — только как референс для позиционирования.
> - Все тексты — HTML-текстом, а не картинкой.
> - Сгенерируй `index.html`, `styles.css` и папку `assets/`.
> - Шрифты: Anastasia Script, Buongiorno…

### Что было сделано
- Исходники — тяжёлые Canva-SVG (10–27 МБ) с base64-растром. Рендерил их в PNG через
  **headless Chrome** (в системе нет librsvg/inkscape; `convert` — это виндовый
  disk-convert, не ImageMagick).
  - **Грабли:** кириллица + пробелы в пути ломают `file://` — копировал в ascii-путь
    `C:/temp/cala/`.
- Разобрал структуру: 9 секций-приглашения + 17 декоративных элементов «Текст абзаца*.svg»
  (прозрачные PNG-ассеты).
- Цвета фона и палитры дресс-кода — пиксельным сэмплингом (Python + PIL).
- Фото пары и коллаж образов — вырезал из отрендеренных страниц.
- Собрал одностраничник из 9 секций:
  1. Обложка — «Дарья & Вадим», дата, каллы + жемчуг
  2. Дорогие гости — текст + календарь May 2026 (22 отмечено сердцем)
  3. Место проведения — особняк, «Дворцовая усадьба 12»
  4. Программа дня — таймлайн с иконками и временем
  5. Дресс код — палитра + образы
  6. Свадьба через — отсчёт + голуби
  7. Пожелания и детали — рамка-плашка
  8. Анкета гостя — RSVP (radio + checkbox)
  9. Финал — полароид пары, монограмма «А М» на кружевном сердце
- Каждая секция — `.canvas` с `container-type: inline-size`, размеры/шрифты в `cqw`
  (масштабируется), пропорции через `aspect-ratio`.

### Замечания, озвученные пользователю
- **Шрифты** Anastasia Script / Buongiorno в системе/проекте **не найдены**. Правило
  «не подбирать, если оригиналы доступны» → оригиналов нет → поставлены кириллические
  заменители (Marck Script / Pinyon Script / Cormorant Garamond), а `@font-face`-слоты
  ждут оригиналы в `assets/fonts/` (положить `.woff2` — подхватятся без правок CSS).
- Отсчёт «Свадьба через» — живой таймер к дате; на дату сессии (после 22.05.2026)
  показывает нули; дата задаётся в `data-target`.

## Часть 3 — Доработки + добавление в конструктор (редактируемым)

### Запрос пользователя
> Если добавить его на сайт в шаблоны, редактировать не станет сложнее? Внеси изменения
> и добавляй в шаблоны редактируемым. В программе дня уменьши иконки, чтобы они не
> загораживали трек и помещались на страницу. Сделай трек змейкой и белым цветом. И
> запусти по треку жемчужину-иконку (из папки), чтобы ездила вместе с прокруткой. Дресс-код
> сделай каруселью из фото. Текст в пожеланиях уменьши, чтобы помещался в рамку, иконку
> колец сверху поставь в правильное положение, не на рамке. Сделай анимацию на всём сайте
> fade-up и анимацию при наведении на фото.

### Доработки по дизайну
- **Программа дня:** иконки уменьшены и не загораживают трек; трек = **белая
  змейка-серпантин** (пунктир); по нему **едет жемчужина** `pearl-bead.png` при прокрутке
  (`getPointAtLength`, как в «Средиземноморье»). Узлы сделаны **вертикальными** (иконка над
  временем/подписью), амплитуда серпантина подобрана так, чтобы трек вился между колонками.
- **Дресс-код:** **карусель** из 3 фото (`dress1/2/3.jpg`) — scroll-snap + стрелки + точки.
- **Пожелания:** текст уменьшен и помещается в рамку; кольца перенесены **внутрь рамки**
  над заголовком (не на бортике).
- **Анимация всего сайта:** `fade-up` через IntersectionObserver. Две версии классов:
  `.fade-up` (translateY + opacity) для обычного контента и `.fade-soft` (только opacity)
  для элементов со своим `transform` (декор, полароид, монограмма, узлы таймлайна) — иначе
  `.in { transform:none }` убивал их flip/rotate/центрирование.
- **Ховер на фото:** `.zoomable` — плавный `scale(1.045)` (не вешать на translateX-центрированные).

### Интеграция в конструктор (паттерн vadimdarya / mediterranean)
- `public/invite/calla/` — `index.html` (с `data-edit`-хуками), `script.js`
  (URL-параметры гостя + `postMessage('wc:data')` живого превью, сборка календаря из
  `weddingDate`, серпантин + follower, карусель, RSVP), `styles.css`.
- `src/components/CallaTemplate.tsx` — клон Mediterranean-обёртки (iframe + postMessage).
- `src/components/TemplatePreview.tsx` — ветка `templateId === 'calla'`.
- `src/lib/constants.ts` — карточка в `TEMPLATES`, `ICON_SETS.calla`, `TEMPLATE_FIELDS.calla`,
  `TEMPLATE_DEFAULTS.calla`.

### Что редактируется
Имена и дата (отдельное окно; из даты строятся календарь с реальными днями недели + сердце
на дне свадьбы, отсчёт и подпись «Ваши …»), тексты приветствия/места/пожеланий/RSVP/финала,
палитра дресс-кода, 3 фото образов, фото пары, пункты программы с иконками.

### Проверка
- `/demo/calla` — открывается, имена и дата приходят из конструктора через `postMessage`.
- Галерея `/templates` — теперь **6 шаблонов** (калла добавлена).
- **Грабли проверки:** headless-Chrome `--screenshot` рендерит layout не по `--window-size`
  (`innerWidth ≈ 482` при окне 430) → правый край в скриншоте обрезается, хотя в реальном
  браузере всё помещается. Геометрию мерил через временный `document.title` +
  `getBoundingClientRect` + `--dump-dom --virtual-time-budget`. Рендерить для проверки на
  ширине ≥ 500.


## Открытые вопросы / можно доделать
- Положить оригинальные шрифты в `assets/fonts/`.
- При желании — контрастнее стрелки карусели или авто-смена слайдов.
